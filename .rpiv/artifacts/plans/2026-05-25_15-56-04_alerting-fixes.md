# Alerting Fixes — Addressing Code Review Findings Implementation Plan

## Overview

Five targeted fixes across bifrost (OSS) and bifrost-enterprise addressing code review findings: add `EachRequestLimit` to GovernanceStore for symmetric request-limit alert evaluation; wrap evaluator calls with `Context.WithTimeout` (5s) to prevent blocking the request path; bound RouteStateObserver goroutines with a non-blocking semaphore; fix cooldown-before-send panic safety via defer+recover; and make `decryptString` idempotent via base64 pre-check.

**Implementation status**: Slices 1-4 were implemented in commit `12d4c0b`. Slice 6 (UI types) was also completed. The sole remaining work is **Phase 5: Test Coverage for Fixes**.

## Desired End State

- OSS governance store exposes request limits for alerting via `EachRequestLimit`
- Evaluator call is timeboxed to 5s with `context.WithTimeout`
- RouteStateObserver goroutines are bounded by a non-blocking semaphore (cap=100)
- Cooldown mark is set in defer after channel sends — permanent consumption prevented on panic
- `decryptString` is idempotent — base64 pre-check skips already-plaintext strings
- All five fixes have automated test coverage verifying correctness and preventing regression

## What We're NOT Doing

- No notifier implementation changes (SSRF is by design, mitigated by RBAC + encryption)
- No rolling window or anomaly detection logic changes
- No e2e test changes (covered by existing e2e suite)

## Phase 1: EachRequestLimit

**Status**: ✅ Already implemented in commit `12d4c0b`

### Overview
Add `EachRequestLimit` method to `GovernanceStore` interface and `LocalGovernanceStore` implementation, providing symmetric request-limit iteration alongside existing `EachRateLimit`.

### Changes Required:

#### 1. GovernanceStore Interface + LocalGovernanceStore
**File**: `plugins/governance/store.go`
**Changes**: Add interface method declaration and sync.Map-based implementation

```go
// EachRequestLimit calls fn for every rate limit that has a request-limit configured.
// Used by the enterprise alerting engine to evaluate request-limit threshold rules.
// This is separate from EachRateLimit because request limits and token limits are
// independent dimensions stored in the same row. A rate limit may have only request
// limits, only token limits, or both.
EachRequestLimit(fn func(rateLimitID string, requestCurrentUsage, requestMaxLimit int64))

// EachRequestLimit calls fn for every rate limit that has a request-limit configured.
func (gs *LocalGovernanceStore) EachRequestLimit(fn func(rateLimitID string, requestCurrentUsage, requestMaxLimit int64)) {
	gs.rateLimits.Range(func(key, value any) bool {
		rl, ok := value.(*configstoreTables.TableRateLimit)
		if ok && rl != nil && rl.RequestMaxLimit != nil {
			fn(key.(string), rl.RequestCurrentUsage, *rl.RequestMaxLimit)
		}
		return true
	})
}
```

#### 1. Alert Manager — Semaphore + Cooldown + EachRequestLimit

**Changes**: Add alertSem field, non-blocking semaphore guard for OnDirectionStateChanged and OnTACOSAnomaly, defer-based cooldown with panic recovery in sendAlert

```go
// alertSem bounds concurrent alert handler goroutines.
alertSem chan struct{} // cap=100, non-blocking acquire

// NewAlertManager:
func NewAlertManager(...) *AlertManager {
    return &AlertManager{
        // ...
        alertSem: make(chan struct{}, 100),
    }
}

// OnDirectionStateChanged — semaphore-guarded:
func (am *AlertManager) OnDirectionStateChanged(...) {
    select {
    case am.alertSem <- struct{}{}:
        go func() {
            defer func() { <-am.alertSem }()
            am.evaluateProviderDegradationAlert(ctx, provider, oldState, newState)
        }()
    default:
        am.logger.Warn("alert semaphore full, dropping event")
    }
}

// OnTACOSAnomaly — semaphore-guarded:
func (am *AlertManager) OnTACOSAnomaly(...) {
    select {
    case am.alertSem <- struct{}{}:
        go func() {
            defer func() { <-am.alertSem }()
            am.RecordLatencyAnomaly(ctx, ScopeTypeProvider, provider, directionKey, penaltyScore)
        }()
    default:
        am.logger.Warn("alert semaphore full, dropping event")
    }
}

// sendAlert — cooldown in defer with panic recovery:
func (am *AlertManager) sendAlert(ctx context.Context, rule *AlertRule, event *AlertEvent, thresholdIndex int) {
    // ...
    ck := CooldownKey{...}
    defer func() {
        if r := recover(); r != nil {
            am.logger.Error("panic in sendAlert for rule %s: %v", rule.ID, r)
        }
        am.lastFired[ck] = time.Now()
    }()
    // ... channel loop ...
}
```

#### 2. Idempotent decryptString
**File**: `stores/configstore/tables/encryption.go`
**Changes**: Add base64 validity check before decrypting to prevent double-decrypt on already-plaintext strings

```go
// decryptString — idempotent (checks base64 validity before decrypting)
func decryptString(value *string) error {
    if value == nil || *value == "" {
        return nil
    }
    // If not valid base64, it's already plaintext — skip.
    if _, err := base64.StdEncoding.DecodeString(*value); err != nil {
        return nil
    }
    decrypted, err := encrypt.Decrypt(*value)
    if err != nil {
        return err
    }
    *value = decrypted
    return nil
}
```

## Performance Considerations

- `EachRequestLimit` iterates the same `sync.Map` as `EachRateLimit` — negligible overhead (one extra Range pass per usage update)
- Context timeout is not freed per-call — `context.WithTimeout` allocates; acceptable for the rate of usage updates
- Non-blocking semaphore (cap=100) bounds worst-case goroutine count to 100 even under sustained 5s cycles

## Migration Notes

- `EachRequestLimit` is additive — no existing callers to migrate
- Removing deprecated methods `EvaluateBudgetAlert`, `EvaluateRateLimitAlert`, `RecordRequest` — must verify zero callers before removal. Grep confirms all three are dead code.
